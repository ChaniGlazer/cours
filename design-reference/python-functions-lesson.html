פרמטרים הם מה שנכנס לפונקציה. return הוא מה שיוצא ממנה. יש גם ערכי ברירת מחדל. נבין את שלושתם עם פיצה, ועם קופסה אחת שעושה בלגן.

מפעל הפיצות

        
בחרו ארגומנטים, וראו איזו פיצה הפונקציה מחזירה. שימו לב מה קורה כשלא שולחים את extra_cheese.

        
def make_pizza(size, topping, extra_cheese=False):
    text = size + " pizza with " + topping
    if extra_cheese:
        text = text + " and extra cheese"
    return text

בלשי קוד

    
מה ידפיס הקוד?

    
בלי להריץ: קראו את הקוד, נחשו את הפלט, ובדקו. חמש חידות, כל אחת עם פינה מסוכנת.

    

    

  







  

    
עכשיו אתם

    
שלושה אתגרים לכתיבה

    
כתבו את הפתרונות בעורך הפייתון שלכם, הריצו, ובדקו שהתוצאה כמו בדוגמה. אחר כך הדביקו כאן והורידו קובץ מסכם.

    

      

        קל
        
1 · זוגי או לא?

        
כתבו פונקציה is_even(n) שמחזירה True אם המספר זוגי, ו-False אם לא.

        
print(is_even(4))   # True
print(is_even(7))   # False

        
      

      

        בינוני
        
2 · חנות עם הנחה

        
כתבו discount(price, percent=10) שמחזירה את המחיר אחרי הנחה. אם לא שולחים אחוז, ההנחה היא 10%.

        
print(discount(200))      # 180.0
print(discount(200, 25))  # 150.0

        
      

      

        אתגר
        
3 · מכה בגיבור

        
הגיבור הוא מילון עם "hp". כתבו hit(person, damage) שמורידה חיים, אבל לא מתחת ל-0, ומחזירה את החיים שנשארו.

        
hero = {"name": "Noa", "hp": 50}
print(hit(hero, 20))  # 30
print(hit(hero, 70))  # 0
