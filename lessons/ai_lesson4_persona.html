1 · מוסיפים הנחיות וטמפרטורה

פתחו את chat.py משיעור 3 והחליפו את כל התוכן בקוד הבא. השורות החדשות מסומנות, והן בתוך הפנייה למודל, עם שמונה רווחים בהתחלה:

chat.py
from openai import OpenAI
client = OpenAI()
history = []
while True:
    text = input("You: ")
    if text == "exit":
        break
    history.append({"role": "user", "content": text})
    response = client.responses.create(
        model="gpt-4o-mini",
        instructions="אתה מאמן כושר אנרגטי ומעודד. ענה בעברית, בקצרה.",
        temperature=0.7,
        input=history,
    )
    answer = response.output_text
    history.append({"role": "assistant", "content": answer})
    print("Bot:", answer)

2 · מריצים ומחליפים דמות

טרמינל
python chat.py

שאלו משהו ושימו לב איך הוא עונה. אחר כך עצרו (exit), החליפו את הטקסט שבתוך instructions לדמות אחרת, והריצו שוב.

🎉

ההנחיות לא נשמרות ברשימה history. הן נשלחות מחדש בכל פנייה, ולכן הבוט לא "שוכח" מי הוא.

מד חום: כמה הוא מעז?

זוכרים שכל תשובה יוצאת קצת שונה? הפרמטר temperature שולט בזה. הזיזו את המחוג:

השאלה: "תן לי שם אחד לחתול", שלוש הרצות
🧊 🔥
* המחשה מפושטת. הערכים נעים בין 0 ל-2.
⚠️

חלק מהמודלים החדשים לא תומכים בפרמטר temperature, ואז תקבלו שגיאה. אם זה קרה, פשוט מחקו את השורה.
