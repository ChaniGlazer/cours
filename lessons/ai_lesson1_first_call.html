הרעיון

אפליקציית AI = קוד שלכם + מודל מוכן

את ה"מוח" שמבין ומשיב לא בונים בעצמנו. חברות כמו OpenAI אימנו מודלים ענקיים, והן נותנות לנו להשתמש בהם דרך האינטרנט. התפקיד שלנו הוא לכתוב את הקוד שמחבר אותם למשהו שימושי.

🧠

המודל

ה"מוח". חי בשרתים של OpenAI, ולא על המחשב שלכם.

🚪

ה-API

הדלת. הדרך שבה תוכנה אחת שולחת בקשה לתוכנה אחרת ומקבלת תשובה.

💻

הקוד שלכם

האפליקציה. מחליטה מה לשאול, ומה לעשות עם התשובה.

🔑

ולמה צריך מפתח? השימוש במודל עולה כסף, ולכן ה-API חייב לדעת מי שואל כדי לחייב את החשבון הנכון. המפתח הוא מחרוזת ארוכה שמזהה אתכם, ולכן השמירה עליו חשובה כמו שמירה על כרטיס אשראי.

הכנות

מכינים את המחשב ומקבלים מפתח

חמישה צעדים, פעם אחת בלבד. את כל הקורס נעשה בתוכנה אחת, Visual Studio Code (בקיצור VS Code). סמנו וי על כל צעד שסיימתם.

1 · מתקינים את VS Code

VS Code היא תוכנה חינמית לכתיבת קוד, ובה נכתוב ונריץ את כל הפרויקט.

א. הורדה והתקנה

היכנסו לקישור, לחצו על Download for Windows, הריצו את הקובץ שירד ולחצו Next עד הסוף. בשלב Select Additional Tasks מומלץ לסמן את Add to PATH.

code.visualstudio.com/download ↗

ב. מתקינים את התוסף Python

פתחו את VS Code ולחצו בסרגל הצד על סמל התוספים (ארבע קוביות, או Ctrl + Shift + X). חפשו Python, בחרו את התוסף של Microsoft ולחצו Install.

התוסף Python בחנות ↗
💡

ב-VS Code יש טרמינל מובנה (חלון פקודות). פותחים אותו מהתפריט: Terminal ← New Terminal.

2 · מתקינים פייתון

פתחו טרמינל ב-VS Code והריצו את הפקודה. אם מופיעה גרסה 3.11 ומעלה, פייתון כבר מותקן ואפשר לדלג לצעד הבא.

טרמינל
PS> python --version
Python 3.12.4

אם מופיעה שגיאה שהפקודה לא מוכרת, היכנסו לקישור ולחצו על Download Python. חשוב מאוד: במסך הראשון של ההתקנה סמנו את התיבה Add python.exe to PATH לפני שלוחצים Install. אחרי ההתקנה סגרו ופתחו מחדש את VS Code.

python.org/downloads/windows ↗

3 · חשבון OpenAI והטענת סכום קטן

א. פותחים חשבון בפלטפורמה למפתחים

זה לא האתר של ChatGPT, אלא פלטפורמה נפרדת שבה מקבלים גישה ל-API. אפשר להירשם עם אימייל או עם חשבון גוגל. ייתכן שתידרשו גם לאמת מספר טלפון.

platform.openai.com/signup ↗

ב. מטעינים סכום קטן

💳

מנוי ChatGPT (גם Plus) לא כולל שימוש ב-API. ה-API מחויב בנפרד, ולכן צריך להטעין קרדיט. בדרך כלל אפשר להתחיל מ-5 דולר, וזה מספיק להרבה מאוד.

  1. היכנסו לדף ה-Billing בקישור שלמטה.
  2. הוסיפו אמצעי תשלום (כרטיס אשראי).
  3. בחרו Add to credit balance והטעינו 5 דולר.
  4. השאירו את ההטענה האוטומטית (Auto recharge) כבויה.
Billing: הטענת קרדיט ↗

הקרדיט משולם מראש. כשהוא נגמר ה-API פשוט נעצר, ולא נוצר חוב.

💡 רגע, על מה בדיוק משלמים? (מודלים וטוקנים, בפשטות)

מודל

"המוח" שעונה. ל-OpenAI יש כמה מודלים: קטנים (בשמות כמו mini) שהם מהירים וזולים, וגדולים שהם חכמים יותר ויקרים יותר. בקורס נעבוד עם מודל קטן, כי הוא מספיק לנו בהחלט.

טוקן

המודל לא קורא מילים שלמות. הוא מפרק כל טקסט לחתיכות קטנות שנקראות טוקנים. לחצו לראות איך משפט מתפרק:

* הפירוק להמחשה בלבד. כלל אצבע: באנגלית, טוקן הוא בערך 4 אותיות. בעברית יוצאים יותר טוקנים לאותו משפט.

איך משלמים?

לפי כמות הטוקנים: גם מה ששלחתם (השאלה) וגם מה שקיבלתם (התשובה). המחיר נקבע לכל מיליון טוקנים, והוא זעיר.

📤 שאלה ארוכה של כמה פסקאות:
שברירי סנט
📥 תשובה של כמה פסקאות:
שברירי סנט, והיא קצת יקרה יותר מהשאלה

במילים פשוטות: סכום קטן, כמו 5 דולר, מספיק לאלפי שאלות עם מודל קטן. המחירים העדכניים נמצאים בדף המחירים של OpenAI, ואת הצריכה שלכם תוכלו לראות בכל רגע בחשבון.

openai.com/api/pricing: מחירים ↗

בדף ה-Limits אפשר להגביל כמה כסף ייצא מהחשבון בחודש, כדי להיות רגועים.

Limits: תקרת הוצאה ↗

4 · יוצרים מפתח API

  1. היכנסו לדף המפתחות בקישור שלמטה.
  2. לחצו Create new secret key.
  3. תנו לו שם שתזהו אותו (למשל course), והשאירו את שאר ההגדרות כברירת מחדל.
  4. לחצו Create, והעתיקו מיד את המפתח. הוא מתחיל ב-sk-.
platform.openai.com/api-keys ↗
⚠️

המפתח מוצג פעם אחת בלבד. אם סגרתם את החלון לפני שהעתקתם, אין בעיה: מוחקים אותו ויוצרים חדש.

שמות הכפתורים והתפריטים באתר של OpenAI משתנים מדי פעם. אם משהו נראה קצת אחרת, חפשו את הדבר הדומה ביותר.

5 · שומרים את המפתח במקום בטוח במחשב

את המפתח לא כותבים בקוד. במקום זה שומרים אותו במחשב כמשתנה סביבה בשם OPENAI_API_KEY. זה "מקום" מוסתר במערכת ההפעלה, והספרייה של OpenAI יודעת לקרוא אותו משם בעצמה. כך הקוד נשאר נקי, וגם אם תשלחו אותו למישהו או תעלו אותו לאינטרנט, המפתח לא יעבור איתו.

א. שמירה

פתחו טרמינל ב-VS Code, הדביקו את הפקודה והחליפו את sk-... במפתח שהעתקתם. השאירו את המרכאות.

טרמינל ב-VS Code
setx OPENAI_API_KEY "sk-..."

אם הפקודה הצליחה, תופיע ההודעה SUCCESS: Specified value was saved.

ב. סוגרים ופותחים מחדש

סגרו את VS Code לגמרי ופתחו אותו שוב. המשתנה נטען רק בתוכנות שנפתחו אחרי השמירה.

ג. בודקים שהכול נשמר

פתחו טרמינל חדש והריצו את הפקודה. היא לא מדפיסה את המפתח, אלא רק בודקת אם הוא קיים.

טרמינל ב-VS Code
if ($env:OPENAI_API_KEY) { "KEY FOUND" } else { "KEY MISSING" }

מופיע KEY FOUND? מעולה, סיימתם. מופיע KEY MISSING? ודאו שסגרתם את VS Code לגמרי ופתחתם אותו מחדש, ושהדבקתם את הפקודה כולל המרכאות.

📝

מומלץ לשמור עותק של המפתח גם במקום פרטי ובטוח, כמו מנהל סיסמאות או הערה מוגנת בטלפון, למקרה שתצטרכו להגדיר אותו שוב. לא בקובץ שמסונכרן לאינטרנט בגלוי, ולא בקבוצת וואטסאפ.

חשוב

כללי הזהב לשמירה על המפתח

🚨

המפתח דלף? פעלו מיד: היכנסו לדף המפתחות, מחקו אותו (Revoke), ויצרו אחד חדש. אחרי המחיקה אי אפשר להשתמש בו יותר, גם אם מישהו הצליח להעתיק אותו.
