1 · פותחים תיקייה לפרויקט

כל פרויקט גר בתיקייה משלו, כמו מחברת נפרדת לכל נושא.

  1. צרו במחשב תיקייה חדשה, למשל ai-course, במקום שקל למצוא (שולחן העבודה או Documents).
  2. ב-VS Code בחרו File ← Open Folder ופתחו אותה. אם נשאלתם אם אתם סומכים על המחברים, אשרו.
  3. פתחו את חלון הפקודות (הטרמינל): Terminal ← New Terminal.
💡

לא בטוחים שאתם בתיקייה הנכונה? הריצו pwd כדי לראות איפה אתם, או ls כדי לראות מה יש בפנים.

📦

2 · מתקינים את ארגז הכלים

את הדיבור עם OpenAI כבר מישהו כתב בשבילנו, בצורת ספרייה: ארגז כלים מוכן. מתקינים אותו בפקודה אחת בטרמינל:

טרמינל
python -m pip install openai

כמה שניות של טקסט שרץ, ובסוף שורה שמתחילה ב-Successfully installed. מופיעות שם גם ספריות נוספות, וזה בסדר גמור: הן באות יחד איתה.

✍️

3 · כותבים את התוכנית

  1. ב-VS Code לחצו על סמל הקובץ החדש (או File ← New File).
  2. קראו לו first_call.py. הסיומת .py אומרת שזה קובץ פייתון.
  3. הדביקו את הקוד ושמרו עם Ctrl + S.
first_call.py
from openai import OpenAI
client = OpenAI()
response = client.responses.create(
    model="gpt-4o-mini",
    input="מה זה API? ענה בעברית, בשני משפטים",
)
print(response.output_text)
⚠️

שימו לב לרווחים. בשורות 4 ו-5 יש ארבעה רווחים בתחילת השורה. בפייתון זה חלק מהקוד. אם הדבקתם ושמרתם, הכול במקום.

🚨

אין כאן מפתח, וכך זה צריך להישאר. לא מוסיפים api_key="sk-..." לקוד, גם לא "רק לבדיקה".

🚀

4 · מריצים

בטרמינל, באותה תיקייה שבה נמצא הקובץ:

טרמינל
python first_call.py

אחרי שנייה או שתיים תופיע תשובה בעברית, בערך כך. המילים שלכם יהיו קצת שונות, ובעוד רגע נבין למה:

הפלט
API (ממשק תכנות יישומים) הוא סט כללים שמאפשר לתוכנה אחת לבקש מידע או פעולה מתוכנה אחרת. הוא פועל כמו מלצר שלוקח את ההזמנה למטבח ומחזיר את האוכל לשולחן.
↔️

בטרמינל של VS Code עברית עלולה להופיע הפוכה או עם פיסוק במקום לא נכון. זו בעיית תצוגה של הטרמינל, לא טעות שלכם ולא של המודל. כשנבנה ממשק web זה ייפתר מעצמו. אם מופיעה שגיאה או סימני שאלה, גללו למטה לחלק "קיבלתם שגיאה".

🎉

זהו! תוכנה שכתבתם שלחה שאלה לשרתים של OpenAI וקיבלה תשובה. כל מה שנבנה בהמשך הקורס מבוסס על זה.
