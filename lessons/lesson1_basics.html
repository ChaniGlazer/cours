print — מציגה על המסך

מה שכתוב בסוגריים של print מופיע על המסך. טקסט כותבים בין מרכאות, ומספרים בלי. לחצו על דוגמה, הריצו, ואז שנו את הקוד ונסו שוב.

משתנה — קופסה עם שם

כותבים שם, סימן =, וערך — והערך נכנס לקופסה. אפשר לשים טקסט (במרכאות) או מספר. נסו: שימו ערך בקופסה, ואז שימו ערך אחר באותה קופסה.

חלק 3 · קלט

input — שואלת ומחכה

input שואלת את המשתמשת שאלה, מחכה לתשובה, והתשובה נכנסת למשתנה. הריצו את התוכנית: היא תעצור ותחכה שתכתבי תשובה ותלחצי Enter. אפשר גם לשנות את הקוד ולהריץ שוב.

המלכודת: input תמיד מחזירה טקסט

הריצו, הקלידו שני מספרים, וראו מה יוצא: בלי int פייתון מחברת אותם כמו מילים. עם int היא הופכת אותם למספרים אמיתיים. לחצו על ״עם int״ (או הוסיפו int בעצמכן) והריצו שוב.
