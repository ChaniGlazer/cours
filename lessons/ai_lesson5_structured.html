מהודעה לטופס

בן אדם מבין "אימון קצר בבית". תוכנה לא. אבל אם המודל יחזיר טופס עם שדות קבועים, הקוד יוכל להציג אותו, לשמור אותו או לסנן אותו. בחרו הודעה:

⬇️ המודל מחזיר
* המחשה. התוכנית האמיתית תיצור תוכנית אימון חדשה בכל פעם.
💡

הטופס נקרא JSON: שדות עם שמות ("title"), ערכים (טקסט או מספרים), ורשימות בתוך סוגריים מרובעים.

בונים

מאמן כושר חכם, בקוד קצר

✍️

1 · קובץ חדש ומדביקים

צרו קובץ חדש בשם workout.py והדביקו:

workout.py
import json
from openai import OpenAI
client = OpenAI()
request = input("What workout do you want? ")
response = client.responses.create(
    model="gpt-4o-mini",
    instructions="""אתה מאמן כושר. החזר JSON בלבד, בעברית, במבנה הזה:
{"title": "...", "minutes": 20, "exercises": [{"name": "...", "sets": 3, "reps": 10}]}""",
    text={"format": {"type": "json_object"}},
    input=request,
)
plan = json.loads(response.output_text)
print(plan["title"], "-", plan["minutes"], "min")
for ex in plan["exercises"]:
    print("-", ex["name"], ex["sets"], "x", ex["reps"])
⚠️

המילה JSON חייבת להופיע בהנחיה. בלעדיה תקבלו שגיאה. וגם: רווחים בתחילת שורה הם חלק מהקוד.

💪

2 · מריצים ומבקשים אימון

טרמינל
python workout.py

כתבו בעברית, למשל "אימון של 20 דקות בבית בלי ציוד", ותקבלו משהו כזה:

אימון ביתי קצר - 20 min
- סקוואט 3 x 12
- שכיבות סמיכה 3 x 8
- כפיפות בטן 3 x 15
🎉

שימו לב: המודל החזיר טקסט JSON, והקוד שלכם פירק אותו לשדות ועיצב אותו. אתם שולטים בתצוגה.

💡

קיבלתם שגיאה? העתיקו אותה ושאלו את ChatGPT מה לתקן (בלי המפתח!). אם מופיעה KeyError, המודל שכח שדה: הריצו שוב או חדדו את ההנחיה.

ההנחיה מגדירה את הטופס

כותבים למודל אילו שדות רוצים, בדיוק כמו בדוגמה.

🔒

json_object

מכריח את המודל להחזיר JSON תקין ולא טקסט חופשי.

🔓

json.loads

הופך את הטקסט לנתונים שפייתון מכיר.

🎯

plan["title"]

שולפים כל שדה בנפרד בעזרת השם שלו.

🧩

המודל מבטיח JSON תקין, אבל לא מבטיח שכל השדות יהיו בו. לכן כדאי להגדיר אותם בהנחיה בצורה ברורה.

📚

רוצים הנחיות מדויקות יותר, שמחזירות בדיוק את המבנה והתוכן שרציתם? יש באתר קורס פרומפטים נפרד, שמוקדש לנושא הזה בלבד.
